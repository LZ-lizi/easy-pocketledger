## **随心记账**

随心记账是使用 DeepSeek 开发的一款开源记账软件，解决市面上大部分记账软件均需要会员才可解锁全部功能的痛点，主要面向于大学生计算生活费的使用场景，有助于防止头脑一热花完一个月生活费的情况。

> 应用内显示的名称是「记账本」，仓库名与项目名是 `pocketledger`。三处叫法尚未统一，见 issue。

#### **应用介绍**

本应用涵盖了记账软件该有的全部功能，可自定义范围广，根据自己的使用习惯随心调整。

~~总之免费的就是好，谁不想白嫖？~~

- **记账**：数字键盘输入，支出 / 收入 / 转账 / 月付四种类型；类别、账户、时间都能改，时间可精确到分钟。
- **明细**：按日列出当月全部条目，每日显示收支合计；可切换日历视图，点某一天只看那天的记录。
- **搜索**：按关键词、日期区间、类别、账户、收支方向、金额区间组合筛选。
- **统计**：本月 / 近 30 天 / 今年 / 学期 / 全部五种时间范围；支出构成圆环图、分类排行、按大类或小类看。
- **预算**：月度总预算 + 分类单独设限，接近或超出上限时发系统通知。
- **账户**：现金、银行卡、信用卡、支付宝、微信、储值卡等；余额可设置锚点校准，自动算净资产。
- **账本**：多个账本互相独立；每个账本可选预算模式（有账户和余额）或累计模式（只记收支）。
- **学期设置**：给统计页的「学期」范围定义日期区间，适用于按学期看开支。
- **月付 / 分期**：建一个计划，到期自动生成那笔账，不用每月手动记。
- **导入**：直接读微信、支付宝导出的账单（CSV 或 xlsx），逐条确认后入账，能记住你的修正。
- **导出与备份**：导出所选账本为 CSV；全部数据一键备份成 `.plbk` 文件，可换机恢复。
- **桌面小组件**：在主屏直接看当月支出或剩余预算。

**全部数据存在本机数据库里，不联网、不上传、没有账号。**

### 自己编译

需要 JDK 21 与 Android SDK（compileSdk 37）。仓库自带 Gradle wrapper，但国内网络下 `services.gradle.org` 经常连不上，
`settings.gradle.kts` 已经把阿里云镜像排在前面。

```bash
git clone <本仓库地址>
cd pocketledger
echo "sdk.dir=<你的 Android SDK 路径>" > local.properties
./gradlew assembleDebug          # 产物在 app/build/outputs/apk/debug/
./gradlew testDebugUnitTest      # 207 个单元测试
```

`local.properties` 已在 `.gitignore` 里，不会进仓库。
